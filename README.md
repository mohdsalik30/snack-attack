3: How to run the Application

* Prerequisites
Before running the application, ensure the following software is installed:
- .NET 9 SDK
- JetBrains Rider (or Visual Studio 2022/2025 with .NET MAUI workload)
- Xcode (for running on iOS/macOS)
- Git
  
* Clone the Repository
Clone the repository to your local machine:
- git clone <https://github.com/mohdsalik30/snack-attack>
- Open the project in JetBrains Rider or Visual Studio.
  
* Restore Dependencies
- Restore the NuGet packages by building the project or running:
dotnet restore

* Run the Application
- Select your target platform (iOS Simulator, Mac Catalyst, Android Emulator, or Windows).
- Build the solution.
- Run the application.
   

4: Background and Motivation

I have a fast-food app, Snack Attack, is an app where you can go and order all your favourite burgers, fried chicken and drinks. The app will provide users, easy, fun and efficient experience while ordering from Snack Attack. The users can browse through the app and look for snack they crave and order it hassle-free. The app was designed keeping in mind the other food ordering app that are bloated with unnecessary features. The motivation for the app, I would say came from several apps like swiggy, uber eats etc. which I like but hate the UI experience because of steps after steps to place a simple order. Building this app helped me and changed my perspective about building apps, I learned about layout controls, grids, collection view, UI styling, implementing tab bar for better experience.

5: Features

- Browse a collection of popular snack items on the home screen.
- Search and filter snacks by name using the search functionality.
- View detailed information about individual snack items.
- Display snack images, names, and prices in a user-friendly interface.
- Navigate seamlessly between pages using .NET MAUI Shell navigation.
- Responsive and modern user interface built with XAML.
- Real-time search results that update as the user searches.
- MVVM architecture for a clean separation between the user interface and business logic.
- Reusable service layer for managing snack data.
- Cross-platform application built with .NET MAUI.
