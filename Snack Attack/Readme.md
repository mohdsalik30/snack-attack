Background and Motivation:

I have a fast-food app, Snack Attack, is an app where you can go and order all your favourite burgers, fried chicken and drinks.
The app will provide users, easy, fun and efficient experience while ordering from Snack Attack. The users can browse through the app and look for snack they crave and order it hassle-free.
The app was designed keeping in mind the other food ordering app that are bloated with unnecessary features.
The motivation for the app, I would say came from several apps like swiggy, uber eats etc. which I like but hate the UI experience because of steps after steps to place a simple order.
Building this app helped me and changed my perspective about building apps, I learned about layout controls, grids, collection view, UI styling, implementing tab bar for better experience.

Features:    
Home page displays a list of popular items, using a collection view, and buttons to see the item details.

All items page where a user can search for his/her favourite snack and place an order.

Items detail page where the user can see the details of the respective snack he/she has chosen, snacks can be added to the cart and removed from the card as well in this page.

Cart page where user can see the snacks he/she has put in the cart and can also edit the cart items there only.

After placing the order, user can see a notification on the screen with a beautiful animation.

There is a tab bar in the app where user can move around the app easily and fast.

There are flyouts where user can learn about us and also find to contact the customer care, either from email or mobile number.
